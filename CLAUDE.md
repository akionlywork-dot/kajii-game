# Merge Game

Suika-style browser game. Plain HTML/CSS/JS + Matter.js. The full spec is in `SPEC.md`.

- Test command: `node --test`
- Before finishing any task, go through the **Acceptance criteria** in `SPEC.md` and check each item that the change affects. Run the tests.
- Pure logic (no DOM / Matter.js) goes in `logic.js` with tests in `tests/`.
- The owner is learning JavaScript: keep code simple, add short comments.
- When asked to explain code, explain it in Japanese, line by line.
- Never delete files in `assets/`.
